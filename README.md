# 🍵 Чайный Бум — Карточка товара

Демо-страница карточки товара для интернет-магазина **Чайный Бум**.

> Сайт размещён на [Vercel](https://vercel.com) и доступен по адресу: [teaboom.vercel.app](https://teaboom-psi.vercel.app)

## 📦 Стек

- **HTML5** — семантическая разметка
- **SCSS** — препроцессор CSS с BEM-неймингом
- **JavaScript** — vanilla JS, без фреймворков
- **Vercel** — хостинг и автоматический деплой

## ✨ Функционал

- Переключение фасовки товара с обновлением цены и артикула
- Индивидуальный счётчик добавления в корзину для каждой фасовки
- Адаптивная вёрстка (десктоп + мобильные)
- Hover-эффекты и анимации

## 🚀 Запуск локально

### 1. Установка зависимостей

```bash
npm install
```

### 2. Запуск в режиме разработки

```bash
npm run dev
```

### 3. Предпросмотр

```bash
npm run preview
```

### 4. Компиляция SCSS вручную

```bash
npm run build
```
